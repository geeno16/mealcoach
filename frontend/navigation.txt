NAVIGATION documentation:

DN - common domen name

Prefix:
no prefix - landing
/app - application

Access states:
guest       - only without a session
no-profile  - authorized, user profile not created yet
pending     - authorized trainee awaiting coach approval
active      - authorized with a ready profile (coach, or confirmed trainee)

Landing entrypoints:
/                               (guest / any)

Application entrypoints:
/app/signup                     (guest)
/app/login                      (guest)
/app/reset                      (guest)
/app/fork                       (no-profile)
/app/pending                    (pending)
/app/profile                    (active)
/app/notifications              (active)

Planned:
/app/posts                      (active, trainee)
/app/stats                      (active, trainee)

/app/trainees                   (active, coach)
/app/trainee/{auth_id}/posts    (active, coach)
/app/trainee/{auth_id}/stats    (active, coach)
